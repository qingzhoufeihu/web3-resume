# Web3 Resume

静态简历站点，直接由 `index.html` 和 `styles.css` 组成，适合用 Vercel 部署。

## 本地预览

直接在浏览器打开 `index.html` 即可。

## Vercel 部署

1. 把当前目录提交到 GitHub。
2. 在 Vercel 导入该仓库。
3. Framework Preset 选择 `Other`。
4. Build Command 留空，Output Directory 留空或填写 `.`。
5. 点击 Deploy。

部署后如果修改简历内容，只需要改 `index.html`，推送到 GitHub 后 Vercel 会自动重新部署。
